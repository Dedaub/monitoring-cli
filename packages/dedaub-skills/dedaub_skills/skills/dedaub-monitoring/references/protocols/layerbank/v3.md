# LayerBank V3 (Aave V3 fork) — Topics, Selectors, Addresses (Robinhood Chain)

**Status:** verified against live Robinhood Chain RPC on 2026-10-30 and the DefiLlama LayerBank adapter (`projects/lineabank/index.js`, "LayerBank V3" block, Robinhood entry added 2026-09-22). Every address was read on-chain from the `AaveProtocolDataProvider` and the `PoolAddressesProvider`. Re-checked on 2026-10-30: `liquidationCall` present as `PUSH3 0xa718a9` in the live Pool impl `0xb8ea4704…7193`.
**Scope:** LayerBank V3 on **Robinhood Chain (4663)**, the market "LayerBank Robinhood Core Market". V3 is an **Aave V3 fork**, unlike LayerBank V1/V2 (own `Core` + `LToken` design, see [core.md](core.md)). Topics and selectors are chain-agnostic and equal to Aave V3 ([aave/v3.md](../aave/v3.md)). Addresses are network-specific. Index in [README.md](README.md).

LayerBank V3 runs the Aave V3 contract set: a `PoolAddressesProvider`, a `Pool` proxy, a `PoolConfigurator` proxy, an `AaveOracle`, an `ACLManager` and per-reserve aTokens / variable-debt tokens. The Robinhood market lists **tokenized equities and ETFs** (NVDA, SPY, QQQ, SGOV, GLD) next to USDG, WETH and cbBTC. DefiLlama reported about $3.76M TVL (free liquidity) and $7.5M borrowed on Robinhood Chain on 2026-10-30.

LayerBank V3 also runs on Plume, Hemi, Nibiru, BOB and Rootstock (DefiLlama adapter). Those chains are outside this reference set and are not enumerated here.

## 6. Detection invariants & gotchas

1. **Same topics as Aave V3, different emitter.** Filter on `(4663, 0x433e21dc…)` to separate LayerBank from any other Aave V3 fork on Robinhood Chain.
2. **The admin is a single EOA** (`0x514c5684…` owns the AddressesProvider and is the ACL admin). An impl swap or a reserve config change needs no timelock. Alert on `Upgraded` and on PoolConfigurator events.
3. **Tokenized-equity collateral.** NVDA, SPY, QQQ, SGOV and GLD prices move with stock-market hours. Oracle staleness outside trading hours is a liquidation risk to watch.
4. **DefiLlama "TVL" is supply minus borrow** (free liquidity) for this market, so the borrowed figure can be larger than the TVL figure. Do not read that as insolvency.

## 8. Verification & sources

- **Addresses:** the DataProvider from the DefiLlama adapter; `ADDRESSES_PROVIDER()`, then `getPool()`, `getPoolConfigurator()`, `getPriceOracle()`, `getACLManager()`, `getACLAdmin()`, `owner()`, `getMarketId()` read live; reserves from `getAllReservesTokens()` and `getReserveTokensAddresses(asset)`; aToken `symbol()` read live. Proxy impls read from the EIP-1967 slot.
- **Topics:** live `eth_getLogs` on the Pool (via `https://rpc.mainnet.chain.robinhood.com`; the publicnode endpoint rejects log ranges). Selectors confirmed as `PUSH4` constants in the Pool impl bytecode.
- **TVL:** `api.llama.fi/protocol/layerbank` (`Robinhood Chain` 3,755,638 USD; `Robinhood Chain-borrowed` 7,496,359 USD on 2026-10-30).
